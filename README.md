# 东芝空调 · Home Assistant 集成

与 Android 应用「东芝空调」4.8.1 使用相同云接口的自定义集成，将东芝空调接入 Home Assistant。

## 主要功能

- **自动发现**：自动发现账号下的所有家庭与房间。
- **空调实体**：每个房间创建一个空调实体，支持开关、运行模式、设定温度，以及按机型能力提供的风速和摆风。
- **风速档位**：独立的风速 Select 实体，提供自动及 1–5 速的完整控制。
- **状态同步**：控制成功后立即在 Home Assistant 中同步状态，并在后台向云端确认；常规状态默认每 30 秒刷新。

## 配置方式

1. 重启 Home Assistant。
2. 打开「设置 → 设备与服务 → 添加集成」。
3. 搜索 **东芝空调**，输入 App 使用的 **手机号** 和 **密码**。

## 注意事项

- 集成依赖东芝空调国内云服务，**断网时无法本地控制**。
- 密码仅保存在 Home Assistant 的配置条目中；登录请求使用与 App 相同的 AES 加密格式，日志不会记录密码或令牌。
- 风扇模式在空调实体中显示为自动、低、中、高（对应协议值 0、1、3、5）；完整档位请使用独立的“风速档位”Select。
- 摆风仅在设备元数据声明 `louver_H` 或 `louver_V` 时显示。
- 本项目为非官方集成，与东芝官方及 Home Assistant 官方无隶属关系。

## 安装

### 方式一：HACS（推荐）

1. 打开 HACS → **集成** → 右上角菜单 → **自定义仓库**。
2. 添加仓库地址 `https://github.com/hlhk2017/toshiba_ac`，类别选择 **Integration**。
3. 在 HACS 中搜索并安装，然后**重启 Home Assistant**。
4. 到「设置 → 设备与服务 → 添加集成」搜索对应集成名称进行配置。

### 方式二：手动安装

1. 下载或克隆本仓库。
2. 将 `custom_components/toshiba_ac` 整个目录复制到 Home Assistant 配置目录的 `custom_components/` 下。
3. 重启 Home Assistant，再在「设置 → 设备与服务 → 添加集成」中添加。
