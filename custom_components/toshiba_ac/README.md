# 东芝空调 Home Assistant 集成

这是与 Android 应用“东芝空调”4.8.1 使用相同云接口的自定义集成。

## 配置

1. 重启 Home Assistant。
2. 打开“设置 -> 设备与服务 -> 添加集成”。
3. 搜索“东芝空调”，输入 App 使用的手机号和密码。

集成会自动发现账号下所有家庭及房间，并为每个房间创建一个空调实体和一个完整风速 Select 实体。当前支持状态轮询、开关、运行模式、设定温度以及按机型能力提供的风速和摆风。控制成功后会立即在 Home Assistant 中同步状态，并在后台向云端确认；常规状态默认每 30 秒刷新一次。

空调实体的风扇模式显示为自动、低、中、高，分别对应协议值 0、1、3、5。独立的“风速档位”Select 提供自动及 1速到 5速的完整控制。摆风仅在设备元数据声明 `louver_H` 或 `louver_V` 时显示；风管机报告为 0 时不会显示无效的摆风控件。

## 云端说明

该集成依赖东芝空调国内云服务，无法在断网时本地控制。密码仅保存在 Home Assistant 配置条目中；登录请求使用 App 相同的 CryptoJS/OpenSSL AES 加密格式，日志不会记录密码或令牌。
